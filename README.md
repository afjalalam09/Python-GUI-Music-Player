# 🎵 Python GUI Music Player

## 🎯 Project Overview
A lightweight and interactive desktop music player application built with Python. This project features a clean Graphical User Interface (GUI) that allows users to browse their local directory, load MP3 tracks, and control audio playback with ease.

## 🛠️ Tech Stack
* **Language:** Python
* **GUI Framework:** Tkinter
* **Audio Library:** Pygame (mixer module)

## 📂 Project Files
* `music_player.py` - The main Python script containing the application logic, event handling, and GUI layout.

## ⚙️ Key Features
* **Playback Controls:** Fully functional Play, Pause, Resume, and Stop buttons for seamless audio management.
* **Local Directory Access:** Integration to browse and load music files directly from the user's computer.
* **Real-time Status:** Displays the current state of the player (Playing/Paused/Stopped).
* **Intuitive UI:** A simple and user-friendly interface designed for a smooth experience.
